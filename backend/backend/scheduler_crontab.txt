# =========================================
#
# This file contains the cron job configuration to run the trending scheduler
# every 3 minutes to collect data from Google Trends, YouTube, and TikTok.
#
# To install this cron job:
# 1. Copy the line below to your crontab: crontab -e
# 2. Save and exit the editor
# 3. Verify with: crontab -l
#
# To remove the cron job:
# crontab -r (removes all jobs) or edit with crontab -e and delete the line
#
# =========================================

# Run trending scheduler every 3 minutes
# Format: minute hour day month day_of_week command

# =========================================
# Cron Schedule Format Explanation:
# =========================================
#
# Field    Allowed Values    Special Characters
# -----    --------------    ------------------
# minute   0-59             * / , -
# hour     0-23             * / , -
# day      1-31             * / , - ?
# month    1-12             * / , -
# weekday  0-7 (0=Sunday)   * / , - ?
#
# Special Characters:
# * = any value
# / = step values (e.g., */3 = every 3rd value)
# , = value list separator (e.g., 1,3,5)
# - = range of values (e.g., 1-5)
# ? = no specific value (used for day or weekday)
#
# Examples:
# */3 * * * *     = Every 3 minutes
# 0 */2 * * *     = Every 2 hours
# 0 9 * * 1-5     = Weekdays at 9 AM
# 0 0 1 * *       = First day of each month
# 0 12 * * 0      = Sundays at noon
#
# =========================================
# Troubleshooting:
# =========================================
#
# If the cron job is not running:
# 1. Check if cron service is running: sudo service cron status
# 2. Check cron logs: tail -f /var/log/cron
# 3. Verify cron job: crontab -l
# 4. Check script permissions: chmod +x trending_scheduler.py
# 5. Test script manually: python3 trending_scheduler.py
# 6. Check log files: tail -f logs/scheduler.log
#
# Common issues:
# - Path issues: Use absolute paths in cron jobs
# - Permission issues: Ensure script is executable
# - Environment issues: Set PATH and other environment variables
# - Database locks: Ensure only one instance runs at a time
